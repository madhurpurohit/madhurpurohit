### 🚀 About Me

- 🧠 **Engineering Philosophy:** I build software from **First Principles** — diving deep into how systems, JavaScript internals, and neural networks actually work under the hood rather than just using abstractions.
- 🔭 **Currently Architecting:** **Archiant** — An AI-Powered Multi-Agent Software Development Team (autonomous AI coders using LangGraph & Pinecone).
- 🏗️ **Core Focus:** Advanced MERN Stack, Next.js, System Design (HLD/LLD), and integrating GenAI (RAG, GraphRAG, LLMs) into scalable web products.
- ⚡ **Problem Solving:** Actively practicing Data Structures & Algorithms in C++.
- 📍 **Location:** Based in Indore, turning complex algorithms into intuitive products.
